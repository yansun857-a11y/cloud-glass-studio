# Cloud Glass Studio 2.2.0

- 新增视觉效果总开关，关闭时移除本扩展注入的样式变量与区域标记，不清除配置。
- 移除主题适配方案选择器和恢复默认参数。
- 保留玻璃模糊、透明度、底色、顶部/输入区、字体和颜色调节。
- 新增自定义字体名称、字重、斜体、行间距、段落间距、文字高亮底色。
- 四套内置模板；自定义模板无限新增、改名、应用、删除。模板包含完整外观参数，不包含总开关。
- 弹窗和抽屉容器默认不应用 backdrop-filter，以减少移动端定位异常风险。

已执行 JavaScript 语法、manifest JSON、ZIP 文件清单检查；尚未在实际 SillyTavern 环境验证。字体选项取决于设备或主题是否加载对应字体。文字底色通过 `mark` 与 `strong` 元素实现，具体主题的 HTML 结构可能影响覆盖范围。
