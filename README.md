# Cloud Glass Studio 2.3.0

## 本版
- 移除全局 SmartTheme / wx 颜色变量写入；字体与文字颜色仅作用于 `#chat .mes .mes_text`，视觉总开关通过作用域 class 启停，关闭时恢复主题原样。
- 正文、强调（strong/b）、次级（em/i/small 及常见辅助类）分别拥有颜色、字号、字重、斜体、荧光笔颜色/透明度/圆角。
- 正文荧光笔通过安全包裹普通文本节点为行内 span 实现；强调和次级文字用行内背景实现。关闭对应荧光笔或总开关会移除正文包装。
- 支持上传 WOFF2、WOFF、TTF、OTF 字体，使用 IndexedDB 保存在当前浏览器本地；不上传到 GitHub/服务器。换设备需重新上传。
- 模板迁移旧版参数，保留已有模板；新增模板保存玻璃、字体和三类文字设置。旧模板自动迁移为新结构。
- 保留玻璃效果与总开关；弹窗、抽屉仍不使用 backdrop-filter。

## 重要说明
- 次级文字默认识别 `em`、`i`、`small`、`.mes_reasoning`、`.commentary`。不同美化主题可能用其他 HTML 结构，因此无法保证自动识别所有主题的特殊次级文字。
- 正文荧光笔需要对聊天正文中的普通文本节点增加行内 span 包装；仅作用于 `.mes_text`，跳过链接、代码、引用语义及已有强调/斜体元素。
- 上传字体仅保存在当前浏览器的 IndexedDB。清理浏览器网站数据可能会删除字体文件；模板引用字体时需要对应字体文件仍存在。
- 关闭总开关时移除本扩展的作用域 class 和标记，不写入/删除酒馆全局主题颜色变量。

## 更新
覆盖 GitHub 仓库同名五个文件后，在 SillyTavern 更新扩展并刷新。升级沿用 `cloud_glass_studio_universal` 设置键；旧版模板和常用参数会迁移。请先备份扩展设置。

已执行 JavaScript 语法检查、manifest JSON 检查及 ZIP 内容检查；尚未在真实酒馆环境实测。


## 2.3.1 修正强调文字识别
- 「强调文字」不再代表粗体 strong/b，而改为识别括号内引用内容。
- 支持中文全角括号 `（……）`、英文半角括号 `(...)`、`【】`、`「」`、`『』`、`〔〕`、`［］`。
- 括号标点本身保持正文样式，括号内文字使用强调文字的独立颜色、字号、字重、斜体与荧光笔参数。
- 处理仅限聊天正文 `.mes_text`，跳过代码、链接、引用块、已有强调/斜体元素等；括号内容若被酒馆拆分到多个 HTML 节点，暂不自动识别。


## 2.3.2 引号引用识别与首次安装默认关闭
- 「强调文字」现在识别引号内的引用内容：中文双引号 `“……”`、中文单引号 `‘……’`、直角引号 `「……」` / `『……』`，以及英文双引号 `"..."`。
- 引号标点本身保持正文样式，只有引号内部文字使用强调文字的独立样式。
- 新安装时视觉效果总开关默认关闭，首次进入不会自动覆盖原主题。
- 已安装升级用户的现有开关状态会保留，不会因为升级而擅自关闭用户已经启用的效果。


## 2.3.3 引号识别兼容性修正
- 引号匹配不再跳过 `strong/b/em/i/small` 等已有行内排版元素中的文本，避免主题先包装文字后扩展识别不到。
- 强调引用样式提高选择器优先级，并对主题内部再次包装的子元素强制应用引用颜色、字号、字重和斜体。
- 代码、预格式文本、链接及脚本样式仍跳过，避免破坏交互与代码排版。


## 2.3.4 引号颜色统一
- 引号标点与引号内部文字现在包裹在同一个强调样式节点中。
- 避免主题原有引用标点颜色（例如青绿色）覆盖扩展设置；引号和引用内容统一使用「引号内引用」颜色及荧光笔样式。


## 2.3.5 修复滑块读数与主题初始化
- 修复玻璃模糊、透明度、顶部/底栏透明度、行间距、段落间距的数值标签不随滑块更新的问题。
- 移除初始化时清理 `--SmartTheme*` / `--wx-*` 全局变量的逻辑。这些变量可能由用户当前美化主题使用；扩展不得在加载时删除它们。
- 保持视觉效果开关默认关闭；关闭时不再触碰酒馆主题变量，避免初次进入后必须切换一次美化才能恢复主题。


## 2.3.6 稳定性修正
- 修复正文荧光笔关闭时误移除引号引用包装的问题；引用样式与正文荧光笔现在互相独立。
- 上传字体只在需要时加载；同一字体不再因每次拖动滑块而反复读取 IndexedDB、创建和撤销 Blob URL，并忽略过期异步加载结果。
- 修正设置面板中残留的旧版“括号引用”说明。
- 正文荧光笔包装会跳过粗体和次级语义元素，避免开启正文底色时覆盖这些元素原有的字重或次级文字样式。
