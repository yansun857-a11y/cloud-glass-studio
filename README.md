# Cloud Glass Studio 2.1.2

以最初 Cloud Glass Studio 的核心功能为基础，整合 2.1.x 通用适配与自定义模板。

## 功能
- 毛玻璃模糊、玻璃透明度、玻璃底色、顶部与底栏透明度
- 正文字体、字号、正文/次要/引用文字颜色
- 通用适配，不再提供三套主题适配方案选择器
- 四套初始模板；可无限新增、改名、应用、删除
- 模板保存在 SillyTavern 扩展设置中，自动保存
- 不提供“恢复默认参数”按钮；模板不会重置适配区域
- 弹窗与设置面板默认不应用 backdrop-filter，避免移动端布局异常

## 安装/更新
将五个文件覆盖仓库 `yansun857-a11y/cloud-glass-studio` 默认分支中的同名文件。确认五个文件来自同一 ZIP 后，再在 SillyTavern 中更新扩展并刷新页面。

## 版本迁移
沿用扩展设置键 `cloud_glass_studio_universal`，保留已有基础参数。首次升级时若没有模板数据，会写入四个初始模板。用户删除全部模板后不会在重启时重新生成。
