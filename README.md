# 云雾玻璃控制台（Cloud Glass Studio）

当前版本：**1.2.0**。设置面板采用 SillyTavern 原生 `inline-drawer` 折叠结构。

一个用于 SillyTavern 的第三方 UI 扩展。提供手机端友好的实时控制面板，可调整：

- 聊天气泡毛玻璃模糊程度
- 聊天气泡玻璃底色与透明度
- 顶部栏透明度独立控制；设置折叠栏、弹出菜单、底部输入区分别支持底色与透明度调节
- 正文字体与字号
- 正文、斜体/次要文字、引用文字颜色
- 四套区分度更高的快捷主题：晴空云雾（冷调蓝白）、深林苔色（浓郁森林绿）、暮色玫瑰（暖调灰粉）、原生素面（尽量交还给酒馆主题）
- 自动保存设置与恢复默认

## 与现有美化的关系

本扩展负责实时调整样式，不替代原来的主题 JSON。建议继续使用你的「微信读书-云雾玻璃版」或「微信读书-云雾玻璃版·清晰字色」美化预设，再启用本扩展。

## 安装

### 方法 A：本地手动安装
1. 解压 `cloud-glass-studio.zip`。
2. 将解压出的 `cloud-glass-studio` 文件夹放入 SillyTavern 的：
   `data/<你的用户目录>/extensions/`
   如果你的部署使用全局第三方扩展目录，也可放入 `public/scripts/extensions/third-party/`。
3. 确认文件结构为：
   ```
   cloud-glass-studio/
   ├── manifest.json
   ├── index.js
   ├── style.css
   ├── settings.html
   └── README.md
   ```
4. 刷新 SillyTavern。
5. 打开「扩展」设置面板，找到「云雾玻璃控制台」。

### 方法 B：Git 安装
将本文件夹内容放入一个 Git 仓库后，可在 SillyTavern「扩展 → 安装扩展」中输入仓库地址安装。

## 使用
在扩展设置面板拖动滑块或选择颜色，聊天界面会立即更新。设置自动保存到 SillyTavern 的扩展设置中。

## 注意
- 字体选项只会使用设备或主题已加载的字体；没有安装的字体会回退。
- 不同 SillyTavern 版本或其他 CSS 美化可能存在选择器冲突。
- 本扩展不上传聊天内容，也不访问对话记录；仅修改页面 CSS 并保存本扩展设置。
- 如果禁用或删除扩展，扩展动态设置不会继续应用；原美化 JSON 本身不会被修改。
